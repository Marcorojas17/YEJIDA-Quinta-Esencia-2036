🔌 Endpoints Disponibles

La API pública de Yejidá permite a desarrolladores integrar cálculos cabalísticos en sus propias aplicaciones. Base URL: https://yejida.api/v1

GET /v1/sefirot
Lista las 10 Sefirot con sus atributos.
GET /v1/sefirot/:id
Detalle de una Sefirá por ID (1-10).
GET /v1/letras
Las 22 letras hebreas con valor numérico.
GET /v1/letras/:letra
Detalle de una letra específica.
GET /v1/guematria/:texto
Calcula la guematria de un texto en hebreo.
GET /v1/niveles
Los 5 niveles del alma con sus correspondencias.
GET /v1/mundos
Los 4 mundos cabalísticos.
GET /v1/nombres-72
Los 72 Nombres del Shem HaMephorash.
GET /v1/tribus
Las 12 tribus de Israel.
GET /v1/angeles/:fecha
Ángel regente según fecha (YYYY-MM-DD).

📥 Ejemplo de Uso

Consulta de las Sefirot con curl:

curl https://yejida.api/v1/sefirot

Respuesta JSON:

{
  "sefirot": [
    { "id": 1, "nombre": "Kéter", "hebreo": "כתר", "significado": "Corona" },
    { "id": 2, "nombre": "Jojmá", "hebreo": "חכמה", "significado": "Sabiduría" },
    ...
  ],
  "total": 10,
  "version": "1.0.0"
}

Ejemplo en JavaScript:

const res = await fetch('https://yejida.api/v1/sefirot');
const data = await res.json();
console.log(data.sefirot);

🔐 Autenticación

La API es abierta para consultas de solo lectura, con límite de 60 solicitudes por minuto por IP.

Nota: Esta API es conceptual. Para implementarla realmente se requiere un backend (Cloudflare Workers, Vercel Functions o similar).
