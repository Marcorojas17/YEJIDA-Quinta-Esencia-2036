# Contribuir a Yejidá Kabaláh

¡Gracias por tu interés! Este proyecto es abierto y toda contribución es
bienvenida.

## 🎯 Formas de Contribuir

- 💻 **Código** — Mejoras, correcciones, nuevas funcionalidades
- 📖 **Contenido** — Artículos, glosario, correcciones
- 🌍 **Traducciones** — Inglés, hebreo, portugués, etc.
- 🎨 **Diseño** — Iconos, ilustraciones, diagramas
- 🔍 **Revisión** — Ortografía, fuentes, accesibilidad

## 🚀 Cómo Empezar

1. **Fork** del repositorio
2. **Clona** tu fork: `git clone https://github.com/TU-USUARIO/yejida-kabalah.git`
3. **Crea una rama**: `git checkout -b feature/nueva-funcionalidad`
4. **Haz tus cambios**
5. **Commit** con mensaje descriptivo: `git commit -m "Añadir: nueva funcionalidad X"`
6. **Push**: `git push origin feature/nueva-funcionalidad`
7. **Pull Request** describiendo los cambios

## 📋 Reglas

- **Respeto absoluto** — No se toleran ataques personales.
- **Fidelidad a las fuentes** — Cita cuando corresponda.
- **Humildad intelectual** — Reconoce lo que no sabes.
- **Sin proselitismo** — Espacio de estudio, no de conversión.
- **Accesibilidad** — Verifica contraste, teclado, lectores de pantalla.
- **Seguridad** — No añadas dependencias externas sin justificación.

## 🎨 Estilo de Código

- **HTML** — Semántico, accesible, con ARIA cuando sea necesario.
- **CSS** — Variables CSS, mobile-first, sin frameworks.
- **JS** — Vanilla, módulos ES6, sin dependencias externas.
- **Indentación** — 2 espacios.
- **Comillas** — Simples en JS, dobles en HTML.
