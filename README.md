## 📖 Descripción

Proyecto web de código abierto que explora la **Kabaláh hebrea**, la
**numerología sagrada**, la **astrología cabalística** y la **geometría
sagrada** mediante 105+ páginas interactivas.

## 🎯 Estructura

| Carpeta | Contenido | Cantidad |

## 🚀 Uso

Abre `index.html` en cualquier navegador moderno o visita la versión publicada:

**https://TU-USUARIO.github.io/yejida-kabalah/**

- 🔒 **OWASP ASVS L2-L3** — Seguridad web
- 💎 **ISO/IEC 25010** — Calidad de software
- ♿ **WCAG 2.2 AA** — Accesibilidad
- 🔐 **AES-256-GCM** — Cifrado de datos
- 🇲🇽 **LFPDPPP + NOM-151** — Protección de datos México
- 🌐 **ISO 27001 / 27017 / 27018** — SGSI (documentado)

## 📚 Características

- ✅ Cálculo 100% local (sin servidores, sin tracking)
- ✅ PWA instalable + modo offline
- ✅ Fondo de geometría sagrada animado
- ✅ Diseño responsive (móvil, tablet, desktop)
- ✅ Accesibilidad completa (lector de pantalla, teclado)
- ✅ Sin dependencias externas (vanilla JS + CSS)
- ✅ Persistencia cifrada en localStorage
