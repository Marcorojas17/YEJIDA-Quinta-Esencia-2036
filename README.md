# ✦ Yejidá Kabaláh ✦

**La Quinta Esencia del Alma** — Un recorrido completo por la Kabaláh hebrea.

## 📖 Descripción

Proyecto web que explora los 5 niveles del alma, las 10 Sefirot, los 4 Mundos,
las 22 letras hebreas y la aritmética divina del Nombre YHVH.

## 🗺️ Estructura

| Carpeta | Contenido |
|---------|-----------|
| `portales/` | 20 páginas temáticas de Kabaláh |
| `herramientas/` | 15 calculadoras interactivas |
| `visual/` | 12 visualizaciones (SVG/Canvas) |
| `practica/` | 12 prácticas y meditaciones |
| `aprender/` | 10 cursos y recursos educativos |
| `comunidad/` | 8 secciones de comunidad |
| `juegos/` | 10 juegos interactivos |
| `extras/` | 20 extras únicos personalizados |

## 🛡️ Estándares

- 🔒 **OWASP ASVS L2** — Seguridad web
- 💎 **ISO/IEC 25010** — Calidad de software
- ♿ **WCAG 2.2 AA** — Accesibilidad
- 🔐 **AES-256-GCM** — Cifrado de datos
- 🇲🇽 **LFPDPPP + NOM-151** — Protección de datos México

## 🚀 Uso

Abre `index.html` en cualquier navegador moderno o visita la versión publicada.
